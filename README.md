# Контрольная работа №2 — ДогПередержка

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap».

**Выполнил:** Гаврилов Григорий, группа ЭФБО-11-25.

## Описание проекта

Учебный сайт по поиску и бронированию передержки для собак. Проект представляет собой многостраничный интерфейс, разработанный с использованием CSS-фреймворка Bootstrap 5. Сайт позволяет ознакомиться с преимуществами сервиса, выбрать проверенного ситтера из каталога, сравнить их, а также оформить бронирование с автоматическим расчётом стоимости и учётом сезонных коэффициентов.

## Страницы проекта

В проекте реализованы 4 основные страницы:
- `index.html` — Главная страница: hero-блок, преимущества, популярные ситтеры, отзывы и модальное окно «Умного подбора» (квиз).
- `catalog.html` — Каталог передержек: панель фильтров, сетка из 8 карточек ситтеров, а также механизм сравнения (до 3 ситтеров).
- `contacts.html` — Контакты: блок статистики «О нас», контактная информация, способы связи и блок FAQ (аккордеон).
- `booking.html` — Бронирование: форма выбора ситтера, дат, дополнительных услуг и умный калькулятор стоимости.

## Реализованные фичи

### 1. «Умный подбор» (Квиз)
Вместо стандартной и перегруженной формы на главной странице внедрен интерактивный пошаговый опрос (квиз). 
При нажатии на кнопку «Найти передержку» открывается модальное окно, где пользователь шаг за шагом выбирает размер собаки, удобный район и желаемые даты. В конце система подсчитывает количество подходящих ситтеров, показывает результат и перенаправляет в каталог с автоматически примененными фильтрами (параметры передаются через URL). В каталоге появляется уведомление, что сработал умный подбор.

### 2. «Сравнение ситтеров» (Таблица сравнения)
В каталоге на каждой карточке добавлен чекбокс «Сравнить». Пользователь может выбрать до 3-х специалистов. 
При выборе хотя бы одного ситтера внизу экрана появляется «липкая» панель с кнопкой «Сравнить». При клике открывается модальное окно с Bootstrap-таблицей, где по столбцам идут выбранные ситтеры, а по строкам — их характеристики (цена, опыт, район, животные). Таблица стилизована в фирменных зеленых цветах сайта. Если выбрано 3 ситтера, остальные чекбоксы блокируются.

### 3. «Оценка стоимости с учетом сезона» (Сезонные коэффициенты)
Калькулятор на странице бронирования стал умнее. Теперь цена за сутки динамически меняется в зависимости от выбранных дат. 
В JavaScript заложены коэффициенты: Новый год (×1.5), майские праздники (×1.3) и летний сезон (×1.2). Если даты пользователя попадают на эти периоды, итоговая сумма пересчитывается, а над блоком с ценой появляется предупреждение (Bootstrap `alert-warning`) с указанием примененного коэффициента и причины.

### 4. «Копирование контактов ситтера в один клик»
На странице бронирования (при выборе ситтера) появляется кнопка «Скопировать контакты ситтера». 
При нажатии в буфер обмена (через современный `navigator.clipboard.writeText`) копируется текст в формате: «Ситтер Анна, тел: +7 999 123-45-67, район: Центральный». В правом нижнем углу экрана выезжает стилизованное Bootstrap Toast-уведомление «Скопировано!».

### 5. Доработка калькулятора и формы бронирования
Форма бронирования была расширена новыми логичными полями:
- Добавлен выпадающий список для размера и веса собаки (2–5 кг, 5–10 кг, 10–25 кг, 25–40 кг, от 40 кг).
- Добавлено поле для текстового комментария (особенности характера, аллергии).
- В поле телефона внедрена авто-маска, которая форматирует ввод в вид `(999) 123-45-67`.
- Калькулятор теперь учитывает не только дни и дополнительные услуги, но и количество собак.
- **Связка страниц:** при клике «Выбрать» в каталоге или на главной странице имя ситтера передается в URL (например, `booking.html?sitter=Анна`), и форма автоматически выбирает нужного специалиста, плавно прокручивая к нему экран.

## Использованные компоненты Bootstrap

- **Навигация:** `navbar` (адаптивное мобильное меню).
- **Сетка:** `container`, `row`, `col-*`, отступы `g-*`.
- **Карточки:** `card`, `card-body`, `h-100`, `shadow-sm`.
- **Кнопки:** `btn`, `btn-primary`, `btn-outline-primary`, `btn-lg`, `rounded-pill`.
- **Значки:** `badge` (`bg-success`, `bg-warning`, `bg-secondary`).
- **Сообщения:** `alert` (`alert-info`, `alert-success`, `alert-warning`).
- **Модальные окна:** `modal`, `modal-dialog`, `modal-content` (для квиза и сравнения).
- **Формы:** `form-control`, `form-select`, `form-check`, `input-group`.
- **Таблицы:** `table`, `table-bordered`, `table-responsive`.
- **Уведомления:** `toast`.
- **Аккордеон:** `accordion` (на странице контактов).
- **Прогресс-бар:** `progress` (в квизе умного подбора).

## Подключение фреймворка

Bootstrap версии 5.3.3 подключён через CDN. 
Собственный файл стилей `css/custom.css` подключён после Bootstrap для корректного переопределения стилей (цветовая палитра, анимации карточек, стилизация таблицы сравнения).
