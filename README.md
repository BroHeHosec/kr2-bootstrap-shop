# Контрольная работа №2 — ДогПередержка

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap».

**Выполнил:** Гаврилов Григорий, группа ЭФБО-11-25.

## Описание проекта

Учебный сайт по поиску и бронированию передержки для собак. Проект представляет собой многостраничный интерфейс, разработанный с использованием CSS-фреймворка Bootstrap 5. Сайт позволяет ознакомиться с преимуществами сервиса, выбрать проверенного ситтера из каталога, прочитать ответы на частые вопросы и оформить бронирование с автоматическим расчётом стоимости.

## Страницы проекта

В проекте реализованы 4 основные страницы:
- `index.html` — Главная страница: hero-блок с кнопкой поиска, блок преимуществ сервиса, популярные ситтеры и модальное окно быстрого подбора.
- `catalog.html` — Каталог передержек: панель фильтров (по району, цене, размеру собаки) и сетка из 8 карточек ситтеров с бейджами статуса.
- `contacts.html` — Контакты: раздел «О нас» со статистикой, контактная информация, способы связи и блок часто задаваемых вопросов (FAQ).
- `booking.html` — Бронирование: форма выбора ситтера, дат и дополнительных услуг, а также автоматический расчёт итоговой стоимости.

## Использованные компоненты Bootstrap

При разработке были использованы следующие компоненты и утилиты:
- **Навигация:** `navbar` (с адаптивным мобильным меню).
- **Сетка:** `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, отступы `g-*`.
- **Карточки:** `card`, `card-body`, `h-100`, `shadow-sm`.
- **Кнопки:** `btn`, `btn-primary`, `btn-outline-primary`, `btn-lg`.
- **Значки:** `badge` (с цветами `bg-success`, `bg-warning`, `bg-secondary`).
- **Сообщения:** `alert` (`alert-info`, `alert-success`).
- **Модальное окно:** `modal`, `modal-dialog`, `modal-content`.
- **Формы:** `form-control`, `form-select`, `form-check`, `form-label`.
- **Дополнительный компонент:** `accordion` (на странице контактов).

## Подключение фреймворка

Bootstrap версии 5.3.3 подключён через CDN. 
Собственный файл стилей `css/custom.css` подключён после Bootstrap для корректного переопределения стилей.
